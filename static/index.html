Что меняет переключатель?
Без фильтров приложения — DedsecAI Studio не добавляет тематических запретов. Отказы, заложенные в самой модели, могут сохраниться.
Строгий / Свой — проверяются выбранные темы и фразы. При ограничениях ответ проверяется целиком до показа.
Проверка тем основана на словарях: возможны ошибки, пропуски и обход через перефразирование. Стопроцентный тематический запрет не гарантируется.
Правила действуют в веб-собеседнике. Прямой API llama.cpp и терминальный Pi обходят эти проверки.
Изменения применяются к следующим сообщениям. Память и история сохраняются.

Добавить GGUF
Разделённая модель загружается целиком: все части выбранного варианта. Проверь лицензию в репозитории.
Без ожидаемого SHA-256 можно проверить формат и вычислить хеш, но подтвердить подлинность файла нельзя.
Файл остаётся на своём месте. Для split-модели выбери первую часть; остальные должны лежать рядом.
